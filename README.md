# Personal Portfolio

GitHub Pages portfolio for Satya.

## Deploy

1. Create a repository named `yourusername.github.io`.
2. Replace `yourusername` and the placeholder links in `index.html`.
3. Add your resume as `assets/resume.pdf`.
4. Push the files to the `main` branch.
5. In GitHub: **Settings → Pages → Deploy from a branch → main / root**.
6. Your site will be available at `https://yourusername.github.io/`.

## Before publishing

- Replace the GitHub, LinkedIn, email, and portfolio placeholders.
- Replace project repository URLs with your real repositories.
- Add `assets/resume.pdf`.
- Add screenshots or demo links once your projects are polished.
